# Verification

Native source version: 0.1.1, commit `89316aa`.

## Local macOS

- Release VST3, AU and Standalone compiled with CMake and Xcode 27 on Apple Silicon.
- `ctest --test-dir build --output-on-failure`: both test suites passed. Ten DSP test groups and five native integration groups cover impulses at 8/44.1/48/96 kHz and 60/120/180 BPM, routing, tap levels/decay, filter slopes, duck/glitch, dry/reset, extreme feedback, block-size independence, automation, host/fallback BPM, bypass, state and native controls.
- AddressSanitizer and UndefinedBehaviorSanitizer core build passed.
- Native editor screenshots were regenerated by `openedmdelay_plugin_tests docs/screenshots` and inspected.
- The Standalone app was launched as an actual macOS process and its window inspected. JUCE's default standalone input mute remains available through Settings.

## Review regressions

Each finding was reproduced in a failing test and passed after correction:

1. Rapid step changes preserve an active delay-head crossfade before accepting the next target.
2. Stutter windows both repeat boundaries, including the midpoint.
3. Filter cutoff changes use a logarithmic 30 ms movement; slope changes crossfade filter states.
4. Preset recall during bypass clears its pending reset exactly once, preserving audio in the first active block.
5. Malformed numeric values in otherwise valid XML are rejected before state replacement.
6. Slider value text includes units on initial editor creation, before any control movement.

The cross-platform workflow uses Xcode 15-compatible, locale-independent state parsing. Current build and release results are available in [GitHub Actions](https://github.com/alanmarcero/openEDMDelay/actions).
