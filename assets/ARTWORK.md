# Artwork

`tape-echo.png` was generated for openEDMDelay using the imagegen tool on 2026-10-27. It is embedded in the native JUCE editor via BinaryData.

Direction: front-facing black brushed-aluminum tape echo mechanism, two graphite reels, magnetic tape, subdued cyan left illumination and amber right illumination, charcoal background, no text/logos/UI controls. Match the existing openEDMFilter palette (#83d4d0 cyan, #d7ac7b amber).

`docs/screenshots/openEDMDelay.png` and `openEDMDelay-glitch.png` are generated by the compiled native integration test, not by image generation. Regenerate using the README command after UI changes.
